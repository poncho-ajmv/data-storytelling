# 02 · Selección de elementos visuales

Base: Knaflic cap. 2, pp. 47–81, y cap. 9 pp. 253–259. Reglas de decisión y controles adaptados.

| Elemento | Cuándo funciona | Restricción y diseño |
|---|---|---|
| Texto simple | Una o dos cifras | Cifra, unidad, periodo y comparación |
| Tabla | Lectura exacta, varias unidades | Encabezados claros, alineación numérica, bordes tenues |
| Mapa de calor | Patrón en matriz | Escala secuencial/divergente justificada; leyenda y valores si necesarios |
| Dispersión | Asociación cuantitativa, atípicos | Unidades, etiquetas de interés, no causalidad |
| Líneas | Evolución continua | Intervalos coherentes, etiquetas directas, foco selectivo |
| Pendientes | Dos momentos y varias categorías | Extremos etiquetados, mismas unidades, evitar cruces confusos |
| Columnas agrupadas | Pocas series discretas | Base cero, grupos claros, espacio entre grupos |
| Barras horizontales | Ranking y nombres largos | Base cero, magnitud u orden natural |
| Barras/columnas apiladas | Total y composición | Segmento prioritario en base; interiores difíciles de comparar |
| Apiladas al 100 % | Proporciones | Ocultan volumen, indicar tamaño de base si importa |
| Cascada | Aportes a cambio neto | Inicio y fin anclados, signos y valores, reconciliación |
| Áreas | Relación donde área tiene sentido | Comparación imprecisa; preferir longitud/posición si importa exactitud |

## Construcción

Barras y columnas: cuantitativo desde cero, positivos y negativos a cada lado, ancho que permita comparar. Ejes o etiquetas según precisión necesaria; evitar redundancia. Orden cronológico para tiempo, natural para ordinal, magnitud para ranking, estratégico si lo exige historia; conservar orden entre vistas sucesivas cuando favorece aprendizaje.

Líneas: tiempo proporcional, no conectar categorías sin continuidad. Y no necesariamente cero, pero escala clara y sin exagerar. Observado distinto de previsto con estilo y etiqueta. Apiladas: total y segmentos con base común más fáciles; si interesa todos los componentes, agrupadas, pendientes o pequeños múltiplos. Mapas de calor: faltantes distintos de cero, etiquetas si precisión requerida. Dispersión: límites, solapamiento, puntos influyentes, no trazar relación causal sin evidencia. Cascada: inicio + aportes = fin; documentar redondeos; puede simularse con columnas apiladas y base invisible.

## Evitar y sustituir

Circular y anillo dificultan comparar ángulos/arcos: barras, texto o 100 % si conviene. 3D altera percepción: 2D. Doble eje Y dificulta asociación y escalas: paneles alineados, etiquetas directas o transformación justificada. Muchas líneas: foco selectivo, paneles separados o ambas. Si restricción obliga a un formato no ideal, declarar compromiso y minimizar daño. No perder el total ni la proporción al cambiar formato. Si hay ambigüedad, comparar dos alternativas con mismos datos. Antes/después: pendientes para dirección, barras pareadas para magnitud, apiladas 100 % para composición. No hay un único gráfico correcto en toda situación.
