# Storytelling con datos 2.0

Skill en español, de instrucciones reutilizables sin dependencias de software, basada en dos fuentes aportadas: Knaflic (282 páginas de transcripción) y Dykes (413 páginas PDF/transcripción). El núcleo metodológico conserva las seis lecciones de Knaflic y los seis módulos originales en una **reconstrucción consolidada** de su contenido. Los módulos 07–16 añaden capacidades fundamentadas en Dykes; 17 proporciona bibliografía y localizadores. No es una traducción íntegra de libros, ni un producto oficial de los autores.

## Uso

Punto de entrada: `SKILL.md`. Mantén `references/` junto a él. Importa el ZIP o descomprime en la ubicación que indique tu entorno compatible con Agent Skills. Si no admite skills, proporciona SKILL.md y referencias como instrucciones y material de consulta. No se instaló en ninguna plataforma ni se verificó compatibilidad específica. La skill se apoya en capacidades de análisis y generación de artefactos del agente anfitrión cuando estén disponibles.

## Nota sobre preservación exacta de v1

El ZIP original 1.0 no estaba accesible en la sesión de consolidación. Este paquete incluye una reconstrucción del núcleo a partir de los archivos fuente y del contenido previo, no una copia byte a byte. Si requieres preservar literalmente cada archivo de v1, usa el complemento separado `complemento-dykes-v2.zip` con tu ZIP original: su script fusiona los módulos nuevos, añade instrucciones de enrutamiento al final de SKILL.md y notas al README sin borrar contenido anterior. No sobrescribe el ZIP original. Se prueba la mecánica de fusión con un paquete de ensayo, no con el ZIP original no disponible.

## Ejemplos de activación

- Aplica storytelling-con-datos a esta hoja y prepara una presentación de cinco minutos para junta directiva.
- Revisa este gráfico, diagnostica problemas y rediseña sin cambiar los valores.
- Elige una representación adecuada para comparar encuesta antes/después.
- Transforma el reporte mensual en una historia de hallazgos, implicaciones y acciones; si es exploratorio, no inventes historia.
- Evalúa con el marco 4D y el test «¿y qué?» qué hallazgo merece convertirse en la historia central.

## Cambios 2.0

Los diez módulos propuestos se incorporan como complemento temático con localizadores de capítulos y páginas. Casos sintéticos, rúbrica, protocolos y fichas son adaptaciones; no se atribuyen a los libros no consultados. El TXT de Knaflic no contiene ilustraciones; las descripciones de figuras de Dykes en español son editoriales, no parte del texto original. Se verifica estructura y referencias de archivos, no se certifica el comportamiento de un agente instalado.
