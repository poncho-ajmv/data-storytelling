# Data Storytelling 2.0

English-language skill of reusable instructions with no software dependencies, based on two supplied sources: Knaflic (282-page transcription) and Dykes (413-page PDF/transcription). The methodological core preserves Knaflic's six lessons and six original modules in a **consolidated reconstruction** of their content. Modules 07–16 add capabilities grounded in Dykes; 17 provides bibliography and locators. This is not a full translation of the books or an official product of the authors.

## Use

Entry point: `SKILL.md`. Keep `references/` alongside it. Import the ZIP or extract it to the location specified by your Agent Skills-compatible environment. If it does not support skills, provide SKILL.md and the references as instructions and consultation material. The skill has not been installed on any platform or tested for specific compatibility. It relies on the host agent's analysis and artifact-generation capabilities when available.

## Note on exact preservation of v1

The original 1.0 ZIP was inaccessible during the consolidation session. This package contains a reconstruction of the core from source files and earlier content, not a byte-for-byte copy. If literal preservation of every v1 file is required, use the separate `complemento-dykes-v2.zip` with your original Spanish ZIP: its script merges the new modules, appends routing instructions to SKILL.md and notes to README without deleting prior content. It does not overwrite the original ZIP. The merge mechanics were tested with a trial package, not the unavailable original ZIP.

## Activation examples

- Apply data-storytelling to this spreadsheet and prepare a five-minute board presentation.
- Review this chart, diagnose problems, and redesign it without changing values.
- Choose a suitable representation for a before/after survey comparison.
- Turn the monthly report into a story of findings, implications, and actions; if exploratory, do not invent a story.
- Use the 4D Framework and “so what?” test to evaluate which insight deserves to become the central story.

## 2.0 changes

The ten proposed modules were incorporated as thematic complements with chapter and page locators. Synthetic cases, rubric, protocols, and worksheets are adaptations; they are not attributed to books that were not consulted. Knaflic's TXT lacks illustrations; the Spanish descriptions of Dykes's figures are editorial, not part of the original text. File structure and references are verified; installed-agent behavior is not certified.
